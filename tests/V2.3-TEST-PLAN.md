# Dutch Vocabulary Trainer V2.3 test plan

## Static checks completed by implementation review
- Application version centralized in `js/version.js` as 2.3.0.
- IndexedDB version raised from 2 to 3.
- V3 migration normalizes existing vocabulary and session records.
- Backup export/import validates the backup envelope before writing.
- Service-worker cache was replaced with the current V2.3 asset list; obsolete V1 file names were removed.

## Browser smoke tests required
1. Open the app and confirm `V2.3.0 Offline` is displayed.
2. Confirm existing vocabulary and packs are still present after the DB upgrade.
3. Start Meaning practice and complete one correct and one incorrect answer.
4. Start each exercise type: Meaning, Recall, Fill Sentence, Choose Word, Production, Mixed.
5. Open Word Packs and verify installed packs and active-pack selection.
6. Import an existing JSON word pack and verify its word count and pack selection.
7. Open Settings > Data Safety and export a backup.
8. Verify the downloaded JSON contains `exportVersion`, `appVersion`, `vocabulary`, `packs`, `sessions`, and `settings`.
9. Restore that backup into the same browser and verify vocabulary and packs remain intact.
10. Refresh the page and verify data and settings persist.
11. If served over HTTPS/localhost, inspect DevTools > Application > Service Workers and verify the V2.3 service worker is active and its cache contains current files.
12. Test offline mode after the service worker has installed: reload with network disabled and confirm the app shell opens.

## Data-safety warning
The current UI restore is merge-only. Keep the exported backup until all tests pass.
