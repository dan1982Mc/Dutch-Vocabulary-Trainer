# V2.4 Stable Core — Development Contract

The V2.4 rebuild is intentionally incremental. The V2.3 application remains untouched on `main` while V2.4 is developed on the `v2.4-stable-core` branch.

## First checkpoint
- Define the architecture rules in `ARCHITECTURE.md`.
- Establish the single `DutchTrainer` namespace.
- Keep database schema 3 and existing vocabulary data unchanged.
- Do not connect the new namespace to the V2.3 runtime yet.
- Do not remove or rewrite existing V2.3 modules in this checkpoint.

## Safety rule
Every subsequent V2.4 commit must leave the branch syntactically valid and must be independently testable before the next subsystem is changed.
